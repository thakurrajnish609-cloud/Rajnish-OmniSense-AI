# Rajnish-OmniSense-AI 🛡️🤖

**OmniSense-AI** is a non-invasive safety monitoring system. It uses **WiFi CSI (Channel State Information)** to detect falls and monitor human activity. Our mission is to provide safety without compromising privacy, specifically targeting **Elderly Care (to prevent Kodokushi)** and **Industrial Workplace Safety**.

## 🌟 Why WiFi CSI?
Unlike cameras, WiFi CSI signals can monitor activity through walls and in complete darkness, ensuring **100% privacy protection**. This makes it ideal for:
- **Elderly Monitoring:** Detecting falls or lack of movement in private homes.
- **Industrial Safety:** Preventing human-machine collisions in factories.

## 🚀 Key Features
- **Privacy-First Fall Detection:** Uses WiFi signal patterns to detect slips/falls.
- **Elderly Monitoring (Anti-Kodokushi):** Alerts caregivers if no activity is detected for a specific period.
- **M2M Safety:** Real-time proximity monitoring between workers and heavy machinery.
- **Unified GUI Dashboard:** Real-time visualization of health and safety logs.

## 📁 Repository Structure
- `src/omnisensing_core.py`: AI logic for processing WiFi CSI patterns.
- `src/smart_safety_glove.py`: IoT wearable integration for active monitoring.
- `src/Omni_GUI.py`: Dashboard for real-time monitoring and alerts.
